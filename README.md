# basalte

Thème omaLauncher / Omarchy — choix libre — basalte islandais

Orgues basaltiques, cascade de Svartifoss, plage noire de Reynisfjara. Minéral, froid, graphite et blanc laiteux.

## Install

Settings → Theme → coller l'URL du dépôt :

    github.com/marc26712/omarchy-basalte

## Contenu

- `colors.toml` — palette (dark)
- `backgrounds/` — 3 fonds 1080×2400 (9:20)
